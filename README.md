# Philo Labs

Open-source organization for experiments, ideas, and production-ready projects.

## Boilerplates

- [next-frontend-boilerplate](https://github.com/philo-labs/next-frontend-boilerplate) — Next.js with App Router, TypeScript, Tailwind, Vitest and CI
- [node-express-boilerplate](https://github.com/philo-labs/node-express-boilerplate) — Node.js REST API with Express, Prisma, TypeScript, Vitest and Docker
- [next-fullstack-boilerplate](https://github.com/philo-labs/next-fullstack-boilerplate) — Full-stack Next.js with App Router, Prisma, Lucia Auth and Docker
